Bookmark Environment Switcher

A compact Chrome and Edge extension that replaces one bookmark base URL with another across an entire bookmark tree.

JavaScriptBookmarks APIChrome + EdgeLocal storage

The friction behind the tool

Developers often keep a folder of deep links into the same application: customer pages, internal tools, dashboards and object detail screens. Switching from production to a development or spoof environment means changing the host while preserving every path.

Doing that manually is slow and error-prone. The Bookmark Environment Switcher turns it into two inputs—source base URL and destination base URL—and one update action.

How the implementation works

The popup requests the full bookmark tree through the browser Bookmarks API, recursively flattens folders into URL-bearing nodes, and applies a string replacement to each match. Updates are written back by bookmark ID.

const bookmarks = await getBookmarks();

bookmarks.forEach(async (bookmark) => {
  if (bookmark.url.includes(sourceBaseUrl)) {
    const updatedUrl = bookmark.url.replace(sourceBaseUrl, targetBaseUrl);
    await updateBookmark(bookmark.id, updatedUrl);
  }
});

The last-used pair is stored in chrome.storage.local, so the popup can restore the developer's normal environment switch on the next use.

A simple reverse path

The Swap action exchanges the two input values. Running Update again then reverses the same base-URL transformation, provided the target still matches the bookmarks. That is intentionally simple and visible.

Operational lesson

Automation that changes many items should make scope and reversal obvious before it optimizes for cleverness.

Important edge cases

The current implementation is a useful proof of concept, but bulk URL changes deserve defensive handling:

  • URL parsing: substring replacement can match text outside the origin; comparing parsed origins would be safer.
  • Preview: showing the exact affected bookmark count and before/after samples would reduce surprises.
  • Completion: awaiting all bookmark updates with Promise.all would make success and failure observable.
  • Rollback: recording the changed bookmark IDs and original URLs would support a one-click undo independent of current input.
  • Validation: normalizing trailing slashes would avoid malformed joins or missed matches.

Small permission surface

The extension asks for bookmark access to read and update URLs, plus storage access for the last-used values. It does not need host permissions or page-content access. Keeping that permission surface narrow makes the utility easier to inspect and trust.

Install from source

The repository includes source and setup screenshots. Clone it, enable developer mode in Chrome or Edge, choose “Load unpacked,” and select the project directory. Review the affected bookmarks before using it with a large or valuable collection.
