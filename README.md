# Gourav Barnwal — Portfolio

Static source for [gouravbyte.github.io](https://gouravbyte.github.io/), the
portfolio and engineering notes of Gourav Barnwal.

The site is intentionally dependency-free: open `index.html` directly or serve
this directory with any static web server.

## Structure

- `/` — portfolio, experience and selected work
- `/about/` — professional profile and engineering approach
- `/projects/` — source-backed project case studies
- `/writing/` — long-form backend engineering guides
- `/sitemap.xml` — canonical indexable URLs

For local preview with root-relative links:

```bash
python3 -m http.server 8000
```
